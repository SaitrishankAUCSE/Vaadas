# Vaadas — Mutual Peer-to-Peer Commitment System

> **Mutual Agreements • Verified Proof**  
> A high-trust, mobile-first fintech application for recording, managing, and tracking mutual peer-to-peer financial and service commitments ("Vaadas") under the Indian IT Act, 2000.

---

## 🚀 Overview

**Vaadas** (Noted) bridges informal trust and institutional clarity. Whether advancing money to friends, family, or contractors, or tracking repayments, Vaadas creates tamper-evident, dual-party acknowledged commitment records with verified OTP audit trails, repayment schedules, and automated reminders.

### Key Features
- **Asymmetrical Financial Position Ledger**: Real-time breakdown of commitments to receive vs. obligations owed.
- **Mutual Dual-Party Verification**: Commitments remain pending until the counterparty reviews and accepts with mobile OTP verification.
- **Audit Ledger & Timeline**: Timestamped event log tracking creation, mutual acceptance, payment milestones, and closure.
- **Payment Reminders**: Configurable WhatsApp, SMS, and In-App notification schedule with friendly, standard, or formal messaging tones.
- **Legal Compliance Notice**: Built-in Terms of Service and Privacy Policy aligned with IT Act, 2000 evidentiary records.
- **Responsive Mobile Frame**: Optimized mobile simulation with responsive screen containment and interactive device wrapper.

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/SaitrishankAUCSE/Vaadas.git

# Navigate to project directory
cd Vaadas

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### Production Build

```bash
npm run build
npm run preview
```
